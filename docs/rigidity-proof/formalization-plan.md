## 3. 数学与接口边界

### P0：固定数据包

新建一个证明数据结构，以原始相位和缩放序列为参数，收集上述已有结论。字段只允许已经证明的性质：局部积分收敛、可测性、非平凡性、几乎处处锥形不变性、几乎处处竖直包含、球内可测竞争者最小性、局部能量和原函数总变差极限。

不得加入 `IsHalfSpace`、光滑性、全局图形性或方向收敛字段。数据包是避免替换不同子序列的记账工具，不是隐藏分类结论。

验收：构造该数据包的唯一入口直接调用现有共同极限定理；任何抽取子序列的节点同时输出保留全部字段的证明。

### P1：周长与 BV 表示的桥接

输入：当前由紧支撑一阶向量场散度测试定义的 `variationalPerimeter`。
输出：局部有限的向量值分布导数测度、其总变差与当前周长相等、极分解、局部 Gauss–Green 公式。

证明拆分：

1. 固定相对紧开集，对散度测试建立有界线性泛函。
2. 通过支撑可控的光滑逼近扩张到连续紧支撑向量场，证明扩张与逼近序列无关。
3. 表示为向量测度，并用单位向量场对偶说明总变差与原上确界相等。
4. 对嵌套开集验证测度限制一致，拼接成局部测度。
5. 证明在零测集上修改相位不改变上述对象。

须先检查 mathlib 的向量测度/Radon 表示现有 API；不存在的桥接不能用定义等同的方式省略。每个步骤都要给出所需局部紧性、可分性、有限维性实例。

### P2：球内最小性到标准局部最小性

输入：现有关于原点同心球、外环上几乎处处一致的竞争者比较。
目标：任意紧支撑相位扰动均不降低周长。

证明：用一个原点小闭球包含扰动支撑，再用更大的原点开球包含它；应用已有比较。若后续需要指定任意开域内的局部周长比较，再用测度表示把两相位在域外的公共周长消去。此消去需要局部有限性和测度局部性，禁止直接对可能无穷的数做减法。

### P3：规范边界及几何正则性——数学核心依赖

输入：P1、P2 和非平凡相位。
输出：密度代表、局部周长的约化边界表示、双侧密度估计、正则部分的光滑极小超曲面结构、奇点维数界。

数学证明分别位于 `bv-minimizers.md` BV1–BV14 和 `gmt-regularity.md` GR1–GR17。实施时按如下次序提取：相对等周不等式；局部截断竞争比较；双侧密度估计；切锥存在与最小性；良好柱的单层公式；压平竞争者；调和高度；小余量正则性；低维稳定锥定理；维数递降。

每个节点必须明确“相位维数、边界维数、奇点维数”三种量，统一使用环境维数，避免错误地把八维边界当作八维环境。

仅写“使用 De Giorgi 正则性”不能通过该节点的数学验收。尤其须按 GR8 构造核心压平、环带可逆的新集合，并用柱面迹证明没有额外拼接周长；不能对不单射的核心套 Piola 公式。GR9 的良好柱面积来自 BV14，不循环引用尚未建立的一般边界可求长性。最后的线性 Schauder、Sobolev 紧性等一般分析前置必须有实际 Lean 实现，不能把文稿允许使用的分析基础误记为 mathlib 已有 API。

## 4. 分类分支

### C1：低维锥分类

对应 `low-dimensional.md`。输入为 P3、锥形不变性和竖直序。
证明与形式化次序：

1. 奇点维数界与锥形不变性排除原点以外的奇点。
2. 构造球面截面，证明其紧性、无边界和极小性。
3. 从相位包含推出向内单位法向竖直分量非负。
4. 由平移变分推导 Jacobi 方程，并从锥上方程降到球面。
5. 对球面积分，处理每个连通分支上的强最大值原理。
6. 分别处理曲率消失与竖直法向分量恒零的分支。
7. 恒零分支转成分布意义竖直导数为零，再证明相位是柱体；利用非原点正则性排除非平坦柱体。
8. 输出几乎处处等于半空间，且记录单位法向和通过原点的信息。

禁止跳过球面截面的连通性/分支处理，也不能从“几乎处处竖直有序”直接取经典法向。

### C2：高维有向极小锥二择一

对应 `one-sided.md`。输出必须明确为：同一极限相位或者几乎处处等于半空间，或者对每个竖直平移几乎处处不变。

奇点集合可能非空，因此不能照搬 C1 的光滑球面积分。`one-sided.md` §5A 已展开奇点覆盖、容量截断、曲率可积性及 Jacobi 极限；按该路线接入 P3，不把 GMM/Farina 分类作为外加公理。

若采用截断路线，验收必须包含：球面面积的局部上界；奇点覆盖；趋于一的紧支撑截断；梯度能量趋零；二阶基本形式可积性；Jacobi 方程极限；平坦分支的全局延拓与分支排除。仅凭奇点“测度为零”不足以对其分部积分。

### C3：单侧界排除柱体

可以直接复用现有 `NoncylindricalPhase.lean`，其证明不需要新的光滑性。
下界给出零相中向下锥；上界给出正相中向上锥。注意正相指标收敛到零并不自动意味着原正相消失。上界继承所需的内部趋一估计必须保留，不能把它替换成纯集合极限。

将 C2 与 C3 组合，得到第三目标所用的半空间极限。

## 5. 共同平坦性分支

此分支要先完成 `flatness-transfer.md` 中 F5 的自然语言证明。其假设必须只包含 P0 的已有结论及分类输出，不增加全局 Lipschitz 图形界、三阶势函数或全局曲率界。

### F0：剖面与距离变量

完整数学证明见 `reaction-and-targets.md` R3 与 `flatness-transfer.md` F1–F2。
Lean 接口应分别输出剖面存在、严格递增、反函数、二阶方程、指数尾部以及距离变量的微分方程。先搜索现有 `RecoveryProfile` 等模块，能复用的构造只补性质，不再定义第二套剖面。

### F1：平面极限下的倾斜能量消失

使用 `flatness-estimates.md` 中的直接积分论证：原函数的局部积分收敛使其方向导数分布收敛；原点球上的质量等式和径向截断使与平面法向的夹角缺陷趋零；Modica 界把该缺陷控制转换为扩散倾斜能量控制。

输出应量化任意固定正半径，不需要一开始构造整套 varifold。此节点用于缩小数学和 Lean 依赖，不能用局部倾斜趋零替代后续定量改进。

### F2：清除估计和界面位置

输入：原能量极小性、非退化势、局部小能量、尺度参数。
目标：远离极限平面的紧集，正相侧一致趋一，零相侧最终恒零；界面局部 Hausdorff 收敛。

完整证明是 `clearing-out.md` CO1–CO7：径向环带函数、取最小值竞争者、边界迹吸收、微观非退化、能量消失与两侧相位。采用的竞争者局部 Lipschitz，符合原接口。小参数常数必须在 Lean 中按 CO3 的吸收不等式依次选出，随后再缩放。

此外先接入 `moving-center-compactness.md` MC1–MC5 及 `sharp-density.md` SD1–SD4。原有恢复声明针对固定原点缩放，需提取不依赖中心的序列版本。MC2 只要求每个目标球单独恢复，不增加未经证明的同时锐恢复断言。SD4 先用局部 SD3 排除平面离开原点，再调用 CO7，避免循环。

### F3：大部分层面的图形化与高度控制

输入：F1、F2、Modica 和正相 PDE。
输出：良好水平集合上层面的 Lipschitz 图表示，坏集合测度控制，归一化高度的 H1 界。阈值远离零与一，常数对阈值紧区间一致。

具体证明见 HA1–HA3、HA8–HA11。良好水平集合必须定义为实际好点的投影；不能定义成坏点投影的补集后仍套用坏点质量估计。原固定参考层值由平均选出，固定其扩张与平均；低尾部缩小阈值时用 HA9.2 保留同一归一化高度极限。HA10 由连续剖面逼近和 CO3 控制零端带宽，不调用自由边界梯度一致收敛。

### F4：调和逼近及强收敛

使用 HA4 的应力通量证明极限弱调和；HA10 给低尾部，HA5 给稳定井尾部，HA6 用精确应力恒等式与完成平方证明强加权梯度收敛。仅有弱收敛只能给下半连续性，不能给余量缩小所需的上界。HA5 的 Bochner 计算按弱形式只用 W 的二阶导数。

本目标势函数只有 C2。源文献中任何涉及三阶导数的步骤，必须重证为仅依赖二阶导数连续模的估计，或提供保持全部极小性/边界条件的逼近定理。不能仅把势磨光而继续使用原解。

### F5：带尺度误差的倾斜改进

从 F4 和调和函数一阶 Taylor 估计导出在一个固定缩小比率上的超额衰减。必须明确：尺度参数、初始超额阈值、允许的能量偏差、倾斜新方向、误差下限及所有常数的依赖。

禁止将文献中“余量大于尺度误差”的前提丢弃。HA11 的反证序列必须先允许 K 趋于无穷，才能获得参数除以倾斜幅度趋零。HA12 在球和旋转等比例柱体间计算常数，得到带停止误差的递推；实际迭代使用 I2b，而非把 I2.3 较强的前提未经核对地搬入。

### F6：跨尺度与跨中心统一法向

按 I2b–I7 证明，先处理无向秩一投影矩阵。质量下界用 MC5；初始阈值和所有自由边界中心的共同起始半径用 SD4。相邻尺度投影差由倾斜及质量下界控制，几何级数给极限；相交大球给跨中心相等。随后 DS1 使用连续相位通量及原图形的连通性确定共同符号，不能直接给每个中心随意选择一个正向法向。

### F7：距离变量和全局滑动

`distance-and-sliding.md` DS1–DS3 从统一粗锥和球内比较给出大平移次序。DS4–DS6 给出只用 C1 反应项的远井方向证明：归一化正 deficit、常系数极限、高斯卷积与对数凸性、继承的大平移次序。它避免对距离方程系数求二次导数。

全局结束优先采用平移次序集合中的切球论证，见该章末段及 `tangent-ball-comparison.md`：反例参数逼近次序集合边界；DS7 保留正相连通；正值接触由强最大值原理排除；零值接触由参数球制造物理切球，再用 Weiss 放大、半球等号与 Hopf 比较排除。该路线每个极限都要保留全空间次序，不能假设平移极限边界仍然光滑。

输出必须是所有正投影方向、所有非负位移、整个空间上的零延拓单调性；不能只得到远处或几乎处处的序。

### F8：末端代数与一维性

完整证明见 `flatness-transfer.md` F3–F4。用向正投影方向的小扰动逼近切向方向，连续性给出双向切向比较，从而切向不变。正相本身的切向不变迫使图形仿射，再构造一维剖面，代入 PDE 与边界条件。

此节点可在 F7 接口确定后独立形式化，但在 F7 数学证明完成前，不应以增加大量末端辅助引理来制造主证明接近完成的印象。

### 7.1 基础分析的入口检查

实现几何之前，先搜索现有项目与 mathlib，记录下列基础工具的实际声明和类型；缺失时单独实现，不在后续定理中冒充现成 API。

| 球面几何与积分 | Gauss、Codazzi、Jacobi、散度定理 | GR1–GR4、两分类章 | 明确曲率号、内外法向和环境维数 |

这些是文稿允许使用的一般分析与微分几何基础。文稿已经展开其在本问题中的计算和应用；Lean 实施仍须证明所有所需基础声明或找到已经验证的库实现。

### 7.2 BV 与极小边界：建议实现次序

| 建议模块 | 数学节 / 前驱 | 精确输出 | 完成检查 |
|---|---|---|---|
| `PerimeterRadon` | BV1，现有周长定义 | 向量分布梯度、极分解、全变差相等 | 双向对偶不等式，局部测度拼接 |
| `PerimeterLocality` | BV2、P2 | AE 修改不变、局部相等、任意紧扰动最小性 | 公共有限测度消去；无穷周长单独分支 |
| `BVCompactness` | BV3 | 卷积误差、平移界、局部积分子列 | 输出严格递增子列索引 |
| `BVBallGluing` | BV4 | 几乎处处半径的截球及迹拼接 | 球面零质量与切片存在分别记录 |
| `MinimizerDensity` | BV5–BV7 | 两相密度、周长上下界、开规范代表 | 代表边界等于周长支撑 |
| `MinimizerCompactness` | BV8 | 极限极小性与连续球周长收敛 | 先固定极限，再选环带半径 |
| `PerimeterVariation` | BV9 | 余子式变换、紧支撑第一变分 | 不在不单射映射上用变换公式 |
| `PerimeterMonotonicity` | BV10–BV11 | 缺陷积分、恒密度齐次、非平凡切锥 | 所有缩放先 AE，再换规范代表 |
| `HalfspaceTangents` | BV12 | 周长几乎处处半空间切图、密度一 | 不先使用余量正则性 |
| `BVColumnGraph` | BV13–BV14 | 良好柱单层、面积与极向量公式 | 证明强局部性后才限制导数测度 |
| `PerimeterFlattening` | GR8 | 有向反 Poincare | 核心新相位、可逆环带、零拼接代价 |
| `PerimeterHarmonicHeight` | GR9–GR12 | 余量归一化、调和极限、旋转衰减 | 两个坏集指数都趋零；固定扩大截断 |
| `PerimeterEpsilonRegularity` | GR7、GR13–GR14 | 整个规范边界的单图、C1α、光滑性 | 每条竖线唯一交点，非仅几乎处处图形 |
| `StableConeSimons` | GR1–GR4 | 光滑稳定锥的低维排除 | 环境维数三至七；二维另用弦替换 |
| `ConeSplitting` | GR5–GR6 | 非顶点切锥增一个平移方向、截面极小 | AE 仿射变换通过积分极限 |
| `SingularDimensionReduction` | GR15–GR17 | 奇点维数至多环境维数减八 | 正含量保留、奇点保持、严格增维 |

先完成 `PerimeterEpsilonRegularity` 再使用“奇点在极限中保持”。先用低维截面归纳排除非顶点奇点，再用 Simons 光滑锥计算；不得交换这两个逻辑步骤。

### 7.3 两个锥分类分支

| 建议模块 | 数学节 / 前驱 | 精确输出 | 完成检查 |
|---|---|---|---|
| `OrderedConeRepresentative` | L1、BV7 | 规范代表的精确缩放与竖直包含 | 原相位 AE 等价仍随输出保留 |
| `ConeLinkGeometry` | L2–L5、GR1–GR4 | 光滑链接、法向符号、球面 Jacobi | 环境八维只允许顶点奇点 |
| `LowDimensionalConeRigidity` | L6–L7 | 低维相位 AE 等于过原点半空间 | 零法向分支以柱体平移回顶点排除 |
| `SingularLinkCapacity` | 高维 §5A A–C、GR17 | 奇集截断、曲率平方可积、曲率乘法向为零 | 截断梯度能量趋零，不只测度趋零 |
| `DirectedConeDichotomy` | 高维 §5A D–E | 半空间或全部竖直平移不变 | 平坦分支延拓及其他分支排除 |
| `OneSidedConeRigidity` | H2–H7、已有 `NoncylindricalPhase` | 同一单侧极限相位是半空间 | 上界、下界分支不混用 |

两个分类输出采用同一个结构：单位法向、半空间过原点、原相位与该半空间 AE 相等。不要把一个分类输出成点集相等、另一个输出成不同的零测集约定，使共同分支反复转换。

## 8. 每个模块交接时必须记录的内容

每次完成一个模块，同时更新一行机器可核查的进度记录：实际声明全名、实际文件路径、数学节编号、依赖声明、LSP/编译结果、打印出的公理列表。建议的模块名在真正创建之前不能进入“已完成”栏。

数学审查特别检查以下五组极限：奇集截断先固定支撑再去奇点；调和近似先选固定阈值再取序列极限；尾部先选误差及阈值再取大指标；任意中心序列的相位恢复先固定目标球；物理小尺度 Weiss 放大与大尺度相位缩放分开。它们是这次审查中实际发现并修正过的问题类型，不能由通用自动化略过。

最终文稿审查结束只代表数学方案可供实现；两个主目标的 `sorry` 消失、完整 Comparator 和 Palomar 登记仍须分别完成并报告真实结果。
